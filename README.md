# Проект управления задачами

Это приложение для управления задачами, позволяющее пользователям добавлять, редактировать и удалять задачи. Приложение использует Django для бэкенда, PostgreSQL для хранения данных, Redis для кэширования и Celery для обработки фоновых задач.

## Запуск проекта
Для запуска проекта используйте следующую команду:

docker-compose up --build

Эта команда соберет образы и запустит все сервисы, описанные в docker-compose.yaml.

## Проверка работоспособности сервисов
После запуска проекта вы можете проверить работоспособность следующих сервисов:

Бэкенд: доступен по адресу http://localhost:8000

База данных (PostgreSQL): доступна по адресу localhost:5432

Redis: доступен по адресу localhost:6379

Celery: проверьте логи контейнера для подтверждения работы.

Celery Beat: проверьте логи контейнера для подтверждения работы

##  GitHub
Задание сдано в виде ссылки на pull request из ветки домашней работы в ветку develop.
Файл docker-compose.yaml и другие изменения загружены в репозиторий GitHub.
В коммиты не попали игнорируемые файлы (например, .env, .idea, venv, __pycache__).
Репозиторий содержит файл .gitignore с правильными настройками для игнорирования лишних файлов.
